sloth 媒体代理：web → 服务端 → 内网客户端

页面上的每一个字节都不在服务端，而在内网客户端的本地目录里。服务端只是搬运。

浏览器 → HTTP(:8080 网关) → RPC over TCP(:8991) → 客户端 http.Do → 本地 FileServer → 原路返回
